## 2026-07-10 · 汇总表重写 + 产品名称修正 + 输出结构优化

### 新增
- **重写汇总表生成器 `summary_generator.py`**：按用户新模板完全重写
  - Sheet 1「汇总表」：分省汇总 + 分地级市汇总（上下排列）
  - Sheet 2「核查明细表」：完整 16 列巡查表格式，不合格行整行标红（字体 `FFFF0000`）
  - 深蓝标题行 `FF003366` + 蓝色表头行 `FF0070C0`
  - 合格标准行补充理论成交价定义：`产品理论成交价格=产品成交价格-打包、配送费`
- **汇总表 M/N/O 列生成**：
  - M 列（产品理论成交价格 = G−L）：源文件公式无缓存值时手动计算兜底
  - N 列（去除平台优惠价 = G+J+K−L）：同上手动计算兜底
  - O 列（照片）：WPS DISPIMG 格式嵌入截图（`_inject_wps_cellimages` 注入 cellimages.xml）
- **合格判定改为基于 M 列**：理论成交价（成交价 − 配送费）≥ 合格线即为合格
- **输出目录按批次分子文件夹**：每次导出在 `output/` 下创建 `巡查表_YYYYMMDD_HHMMSS/` 子文件夹，巡查表与汇总表集中存放

### 修复
- **雪花啤酒 清爽/勇闯 混淆**：`8°P清爽` 被误判为清爽，实际应为勇闯。修复：检测到"清爽"关键词时，若同时存在 `°P`（带 P）则归为勇闯，仅 `°` 则归为清爽
- **老雪规格**：OCR 无容量信息时默认 500ml，修复为老雪固定 `640ml*12瓶`
- **青岛 110P OCR 误读**：OCR 将 `11°P` 识别为 `110P`，修复用正则 `(\d{2})0[Pp]` 提取前两位
- **燕京 U88 OCR 误读**：OCR 将 `U8 8°P` 识别为 `U88°P`，修复 `if num == "88": num = "8"`
- **青岛白啤无关键词**：标题 `【整箱】青岛啤酒 110P小.` 无"白啤"文字，修复：度数为 11 时默认归为白啤（11° 是白啤标志度数）
- **规格从缩略图提取**：OCR 缩略图区域（left < 0.12）的"12听装"与规格行"12瓶"冲突，修复：提取缩略图标签为 extra_text，"X听装"模式优先
- **WPS cellimages 图片提取**：`_extract_images_from_xlsx` 成功提取 70 张图片，汇总表文件从 9KB 增至 11.5MB

### 优化
- **产品名称标准化签名扩展**：`_normalize_product_name(title, spec, sub_title="", extra_text="")`，合并副标题和缩略图文本用于度数检测
- **雪花系列细分**：superX / 老雪 / 勇闯 / 清爽四类，各按度数细分
- **青岛系列细分**：原浆 / 奥古特 / 2000 / 白啤 / 纯生 / 经典 / 清爽七类
- **百威系列细分**：纯生 / 铝罐 / 普通三类，按度数细分

  - 删除 `qualification_generator.py`
  - 删除 `price_stats.py`（更早期版本，无引用）
  - 删除 `main.py` 中的「📊 生成合格率统计表」按钮及 `_generate_qualification()` 方法
