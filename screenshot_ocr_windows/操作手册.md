# 价格核查软件 Windows 版操作手册

## 一、软件是做什么的

本软件可以把美团等平台的商品截图自动识别成价格核查表。

基本流程：

`导入截图 -> 开始 OCR 识别 -> 检查和修改 -> 设置店铺城市 -> 导出 Excel`

第一次使用时，只要按下面的步骤操作即可。

## 二、开始使用

### 1. 打开软件

双击运行：

`PriceCheckOCR.exe`

如果使用的是源码版本，双击：

`start.bat`

首次打开可能需要等待一会儿，这是程序正在启动 OCR 引擎，属于正常情况。

### 2. 导入截图

软件顶部有以下几种导入方式：

- **选择图片**：选择一张或多张截图。
- **上传压缩包**：选择一个 `.zip` 压缩包，软件会自动读取里面的图片。
- **粘贴截图**：先在微信、截图工具或其他软件中复制图片，再点击此按钮。
- **拖拽导入**：也可以直接把图片或压缩包拖到软件窗口中。

导入后，顶部会显示已选择的图片数量。

如果选错了文件，点击 **清空列表** 后重新导入。

## 三、开始识别

1. 确认截图已经导入。
2. 点击 **开始 OCR 识别**。
3. 等待进度条完成。

识别过程中不要关闭软件，也不要重复点击识别按钮。

识别完成后，结果会显示在下方表格中。

### 识别完成后的城市选择

识别完成后，软件会先显示“选择省份和城市”窗口。这个窗口是为了帮助系统在正确的城市范围内匹配店铺。

操作方法：

1. 勾选截图涉及的省份。
2. 在城市列表中勾选一个或多个城市。
3. 点击 **确定**。

如果暂时不确定城市，可以点击 **暂不设置城市**，系统不会自动匹配，之后再使用“一键设置城市”或“联网识别城市”处理。这样可以避免同名店铺被匹配到其他城市。历史 `shop_city.db` 仅作迁移参考，系统不会据此自动填入城市；自动匹配只会使用人工确认或人工投喂的学习记录。

城市匹配完成后，未匹配的店铺不会再自动弹窗，用户可以继续检查表格。

## 四、检查和修改表格

识别结果显示在表格中。建议导出前逐行检查以下内容：

- 所属区域
- 平台
- 店铺名称
- 产品名称
- 原价和成交价
- 打包费、优惠、红包、配送费
- 备注

发现错误时，直接点击单元格并修改即可。

店铺城市可以直接修改“所属区域”这一列。修改后的内容会用于导出表格。

如果需要复制表格内容：

1. 用鼠标选中表格区域。
2. 按 `Ctrl+C`。
3. 到 Excel 或其他表格中按 `Ctrl+V`。

## 五、统一设置店铺城市

如果有多家店铺没有识别出城市，可以使用单独的按钮处理。

1. 点击 **统一设置店铺城市**。
2. 选择一个省份和城市。
3. 勾选属于该城市的店铺。
4. 点击确定。
5. 如果还有其他城市，继续选择下一个城市。
6. 全部设置完成后关闭窗口。

这个按钮只处理当前没有填写城市的店铺，不会覆盖已经识别或手动填写的城市。

人工确认的店铺和城市会保存到知识库。以后再次识别相同店铺时，系统会优先使用这次确认的结果。

## 六、联网识别城市

本地数据库没有找到城市时，可以使用联网识别。

1. 点击 **联网识别城市**。
2. 勾选涉及的省份。
3. 勾选允许搜索的城市。
4. 点击 **开始联网识别**。
5. 等待识别完成。
6. 对“待人工确认”的候选店铺，按 POI 名称和候选依据选择城市；不确定时保留 **暂不填入**。

联网识别会把店铺名称发送到百度地图接口进行搜索，因此使用前请确认网络正常。系统只发送店铺名称；本地学习库会记录授权时间、请求时间、允许的城市范围、候选和最终人工裁决，便于后续核对。

重要：联网识别只会接受刚才勾选城市范围内的结果。范围外的地址会被自动拒绝，不会写入表格。名称相同、分差过小或 POI 名称无关的候选不会自动填入；只有在确认窗口主动选择的城市才会保存到知识库。

## 七、导出 Excel

检查表格无误后：

1. 点击 **导出 Excel**。
2. 软件会自动按品牌写入对应的工作表。
3. 导出完成后，软件会打开导出文件所在文件夹。

导出的巡查表会保留模板格式，并保留价格计算公式。用 Excel 或 WPS 打开后，可以查看和重新计算公式。

导出文件通常保存在桌面上的批次文件夹中。

建议每次导出后不要覆盖旧文件，保留不同批次的结果，方便后续查找。

## 八、生成汇总表

如果需要生成价格合格率汇总：

1. 点击 **生成汇总表（含截图）**。
2. 选择刚才导出的巡查表 Excel 文件。
3. 选择产品类型：燕京 U8 或漓泉 1998。
4. 选择要统计的省份。
5. 点击确定生成。

1998 的 12 瓶/12 听规格按省份执行价格标准：广东合格线 70 元、第二档 65 元；广西合格线 60 元、第二档 55 元。汇总表会按省份分别计算，低于第二档线的记录单独统计。

汇总表包含：

- 分省汇总
- 分地级市汇总
- 核查明细表
- 原始截图

汇总表中的价格计算公式会保留。

## 九、生成总结话术

如需生成汇报文字：

1. 点击 **生成总结话术**。
2. 选择巡查表 Excel 文件。
3. 选择省份。
4. 等待文字生成。
5. 点击 **复制到剪贴板**，再粘贴到微信、Word 或邮件中。

## 十、查重核查

导出前可以点击 **查重核查**，检查是否存在重复记录。

软件会根据以下内容判断是否重复：

- 店铺名称
- 平台
- 城市
- 理论成交价

在查重窗口中勾选需要删除的重复行，然后点击 **删除选中行**。

建议先确认重复记录确实是重复数据，再删除。

## 十一、知识库

点击 **知识库** 可以查看和管理系统记住的店铺信息。

常用场景：

- 查看已经记住的店铺城市。
- 导入人工修正后的 Excel。
- 查看冲突店铺。
- 重新匹配当前店铺。
- 清理被误导入的产品规格、表头或数值记录。

一般情况下，不需要频繁操作知识库。人工修改并确认城市后，系统会自动学习。

## 十二、常见问题

### 1. 双击后没有打开

请确认使用的是 Windows 10/11 64 位系统，并重新双击 `PriceCheckOCR.exe`。

如果使用源码版本，请先运行 `install.bat`，再运行 `start.bat`。

### 2. OCR 识别失败或程序闪退

请把以下日志文件发给技术人员：

`%LOCALAPPDATA%\LQPriceCheck\logs\application.log`

打开方法：

1. 按 `Win+R`。
2. 粘贴上面的路径。
3. 按回车。

### 3. 本地匹配没有结果

先确认店铺名称是否识别正确。如果店铺名称有明显错误，可以直接修改店铺名称，再点击 **统一设置店铺城市** 手动确认。

确认后，系统会记住该店铺，下一次通常可以自动匹配。

### 4. 联网匹配找不到店铺

请检查网络连接，并确认在联网识别窗口中勾选了正确的省份和城市。

如果仍然找不到，可以使用 **统一设置店铺城市** 手动设置。

### 5. 表格里的价格看起来没有计算

请使用 Excel 或 WPS 打开导出的文件，并等待软件自动计算。如果仍未更新，可以在 Excel/WPS 中按重新计算或重新打开文件。

### 6. 如何重新做一批截图

点击 **清空列表**，重新导入新的图片或压缩包，然后按照本手册的流程再次操作。

## 十三、最简单的记忆方法

日常只记住这 5 步：

1. 导入截图。
2. 点击开始 OCR 识别。
3. 选择省份和城市。
4. 检查表格，必要时点击统一设置店铺城市。
5. 点击导出 Excel。
